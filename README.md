# hienlpv.github.io

GitHub Pages for hienlpv projects. `nanoremote/` is published from `site/` in the Nano Remote repo (see its docs/environment.md); edit it there, not here. `plopsy/` is published from `site/` in the Plopsy repo in the same way.

`cca-f/` is a copy of https://lnquyen.github.io/cca-f/ (CCA-F exam prep) edited directly in this repo. Added on top of the original: study progress is remembered in `localStorage` (`cca-f-*` keys, helper in `cca-f/assets/js/progress-store.js`) for the checklist, Quiz 1, Interactive Quiz and Practice Exam.
